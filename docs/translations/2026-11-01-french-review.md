# French review — website edits of 2026-11-01

Hi Margaux! These are the French strings that the 2026-11-01 edits added or changed. Anything in **Part 1** is a Claude draft that's live on the site now, so the French version never falls back to English. Please correct it, or leave it alone if it's fine. **Part 2** is French you already reviewed, but the English next to it has changed or it reads differently, so it may need another look.

How to send edits back: fill in the **Your version** line under any item you change, and leave the line blank if the current French is fine. Reply with this file (or just the edited items). In the code, each draft is wrapped in `draft(…)` in `src/content/strings.ts`. Once you've approved an item, it goes back to a normal string.

French typography note: dress codes render as `Dress Code : Garden Party`, with a space before the colon. Say so if you'd rather use a non-breaking space or a different label, e.g. `Tenue :`.
